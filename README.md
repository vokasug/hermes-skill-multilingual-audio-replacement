# multilingual-audio-replacement

Навык Hermes Agent для **переозвучки видео и аудио на другой язык с клонированием голоса** — полностью локально, без облачных сервисов.

## Какие задачи решает

- Переозвучить видеоклип (MP4/MOV) или аудиозапись (WAV/MP3/M4A) на другой язык, **сохранив голос оригинального диктора** — тот же тембр говорит на целевом языке.
- Аккуратно **убрать речь из записи, оставив фон нетронутым**: музыка, шум улицы, звуковые эффекты продолжают звучать без «провалов» и приглушений.
- Получить «минусовку» (дорожку без голоса) из любой записи — промежуточный результат навыка.
- Собрать финальный файл, где на оригинальных таймингах звучит переведённая речь склонированным голосом поверх нетронутого фона.

## Что умеет

1. **Распознавание речи** с таймкодами слов и надёжным определением языка (двухпроходная схема: автоопределение + принудительный язык, кросс-проверка двумя моделями — автодетект Whisper способен уверенно ошибаться).
2. **Интеллектуальное отделение голоса от фона** нейросетевой моделью источникового разделения: на выходе чистая фоновая дорожка и изолированный голос.
3. **Клонирование голоса** по 3–10 секундам изолированной речи и синтез произвольного текста на 10 языках (включая русский) этим голосом.
4. **Сборку результата**: фоновая дорожка + синтезированные фразы на оригинальных позициях, с ограничителем громкости; видеопоток копируется без перекодирования.
5. **Самопроверку**: итоговый файл автоматически транскрибируется на целевом языке (все фразы на месте) и на исходном (речи оригинала не осталось).

## Как работает

```
вход (видео/аудио)
   │
   ├─► Whisper (MLX) ──► транскрипт + таймкоды фраз, определение языка
   │
   ├─► MelBand RoFormer ──► (vocals) голос  +  (other) чистый фон
   │         │
   │         └─► референс для клонирования (нарезка по таймкодам)
   │
   ├─► перевод фраз агентом (с проверкой: фраза влезает в своё окно)
   │
   ├─► Qwen3-TTS Base (MLX) ──► каждая фраза голосом-клоном
   │
   └─► ffmpeg: фон + фразы на исходных таймкодах ──► итоговый файл
```

Ключевая идея: вместо приглушения оригинальной речи (которое выбивает дыры в музыке) используется нейросетевое разделение источников, поэтому фон звучит непрерывно. Клонирование выполняется по изолированному голосу, а не по исходному миксу — это критично для качества клона.

## Технологии

| Компонент | Технология | Роль |
|---|---|---|
| STT | [mlx-whisper](https://github.com/ml-explore/mlx-examples) (Whisper large-v3-turbo на MLX) | транскрипт, таймкоды, язык |
| Разделение источников | [audio-separator](https://github.com/nomadkaraoke/python-audio-separator), модель MelBand RoFormer (Kim) | голос ↔ фон |
| TTS / клонирование | [mlx-audio](https://github.com/Blaizzy/mlx-audio) + [Qwen3-TTS-12Hz-1.7B-Base](https://github.com/QwenLM/Qwen3-TTS) (8-bit, MLX) | синтез клоном |
| Сборка | ffmpeg | микс, муксинг, кодирование |
| Окружение | uv + Python 3.12 venv | изолированная установка |

Всё работает локально на Apple Silicon (MLX), приватность сохраняется: файлы не покидают машину.

## Требования

- macOS на Apple Silicon (M1 и новее)
- Homebrew, ffmpeg, uv
- ~10 ГБ свободного места (модели скачиваются с Hugging Face при первом запуске)

## Установка (с чистого Mac)

```bash
brew install ffmpeg uv

uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python \
    mlx-whisper mlx-audio soundfile \
    audio-separator onnxruntime audioread
```

Модели (`mlx-community/whisper-large-v3-turbo`, `vocals_mel_band_roformer.ckpt`, `mlx-community/Qwen3-TTS-12Hz-1.7B-Base-8bit`) скачиваются автоматически при первом использовании.

## Структура

- `SKILL.md` — инструкция навыка для агента: установка с нуля, пошаговый процесс, подводные камни, критерии проверки
- `scripts/clone_tts.py` — пакетный синтез списка фраз одним клонированным голосом (модель загружается один раз)
